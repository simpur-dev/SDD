一次任务的闭环（正向对齐 → 反向校验）

  • 1
    入库 需求/设计/代码/测试/规则解析、AST 建图、写入 seekdb，注册 Source
  • 2
    取上下文 任务驱动混合检索 + 有效性判定，输出四段式 Context Bundle
  • 3
    开发验证 Agent 改代码、跑测试；决策与进度写入记忆
  • 4
    反向回写 diff / 测试结果回写 seekdb，提交 Handoff 与任务结果
  • 5
    接续 新会话 resume：代码 · 库 · 记忆三方核对，再生成最新上下文
